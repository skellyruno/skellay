# Fixed-time allpass feedback delay — 2026-11-27

Independent optional native ResearchAllpassDelay. Original ResearchDelay, Classic, Modern, Bank, UI, and serialized controls untouched. Fixed-time prepare-only controls; all allocations off process path. Fraction f in [0.05,1) uses first-order allpass H(z)=(a+z^-1)/(1+a*z^-1), a=(1-f)/(1+f); f=0 bypasses it exactly. Reject 0<f<.05 rather than silently rounding or approximating. Magnitude is unity in fixed-control linear regime, but delay/group delay is frequency dependent. One-pole lowpass damping in feedback, with zero cutoff argument disabling damping; output-only mid/side width does not affect feedback state. Feedback limited to .95, convex stereo crossfeed, bounded history +/-32. Not a universal peak or energy-safety guarantee for arbitrary input, time-varying settings or nonlinear clipping.

432 fixed configurations, 3 rates x 4 fractions x 2 feedback x 3 crossfeed x 2 damping x 3 widths; four isolated echoes x five frequencies x two complex modes = 17,280 checks. Max absolute complex error 3.21824e-15 vs 1e-8 threshold. GCC optimized and ASan/UBSan passed. Six-rate stress checks width-independent mid, finite bounded-input outputs, exact dry, reset and rejection of near-integer unsupported fractional setting. New CTest registered. No dynamic delay-time transition support yet; this is not the selectable fourth model.

Private vocal calibration (shared decompiler benchmark): 36 distinct fingerprint-checked excerpts at 44.1 kHz, isolate high-energy 125ms segments, 250ms+.5 sample delay, feedback .75, crossfeed 0, full wet, no damping, width 1.
